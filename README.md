## 使用步骤

1. 将本ZIP解压到独立小组目录。可以用支持Markdown的编辑器填写；也可用Word等熟悉的工具保存等效成果，并同步更新文件入口。
2. 网页上传时，在自己的私有仓库中保留相同目录结构。若已有本地Git仓库，可按操作说明第9步推送；首课不强制命令行。
3. 维护已有Issue的负责人、完成条件、成果链接和实际检查结论；任务模板可按组内需要使用。
4. 围绕发布、检索、下单、取消建立真实Issue，指定真实账号，写完成条件，并加入Todo／In Progress／Done看板。
5. 邀请课程指定账号加入仓库Collaborators，单独为该账号开通Projects的Read权限；组员看板权限为Write。账号以课堂通知为准，两处均须确认。

## 阶段版本

实验一lab1按第2次课材料v1.4、指导书v1.7登记：先提交脱敏共享需求成果，再在全组“互评与提交记录”末尾填写仓库链接和最终提交页面链接；该链接已包含完整SHA，不再另抄哈希或另做登记表。看板与成果入口在本README，个人Issue或贡献链接写入本人报告。

最终由组长提交一个小组ZIP，仅包含每人的完整Word报告和全组一份互评与提交记录Word。完整用例图、需求表及全部三个详细用例直接放入个人报告；绘图源文件、单独图片、PDF报告和过程截图包不再必交。身份完整的报告经课程渠道提交。实验二、三的阶段登记按各自最新指导书执行。

三项实验为4、4、8课时。占位文字和空表不算完成；个人报告仍按模板完整提交，私有仓库不因检查而改为公开。
