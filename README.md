## 使用步骤

1. 将本ZIP解压到独立小组目录。可以用支持Markdown的编辑器填写；也可用Word等熟悉的工具保存等效成果，并同步更新文件入口。
2. 网页上传时，在自己的私有仓库中保留相同目录结构。若已有本地Git仓库，可按操作说明第9步推送；首课不强制命令行。
3. 确认隐藏目录.github中的任务模板也已上传；必要时用Create new file创建完整路径.github/ISSUE_TEMPLATE/task.md并粘贴内容。
4. 围绕发布、检索、下单、取消建立真实Issue，指定真实账号，写完成条件，并加入Todo／In Progress／Done看板。
5. 邀请课程指定账号加入仓库Collaborators，单独为该账号开通Projects的Read权限；组员看板权限为Write。账号以课堂通知为准，两处均须确认。
