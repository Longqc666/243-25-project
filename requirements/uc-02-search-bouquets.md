## 1 用例基本信息

| 字段 | 内容 |
|---|---|
| 编号 | UC-02 |
| 名称 | 检索花束 |
| 目标 | 顾客按需求找到当前已上架且仍可预订的花束，并选择进入详情。 |
| 主要参与者 | 顾客 |
| 次要参与者 | 商家通过UC-01/UC-07维护商品信息，间接提供查询数据；管理员仍负责账号与违规内容管理，不执行顾客检索流程。 |
| 触发条件 | 顾客进入检索页，提交条件、选择排序或翻页。 |
| 前置条件 | 系统已提供顾客检索入口及花束数据读取能力；可以没有任何可见花束。“存在匹配结果”“仍有库存”均不作前置条件，而在读取时判断。登录与角色入口遵循FR-08，本用例不另行决定匿名访问策略。 |
| 成功后置条件 | 返回当前条件下的列表、总数、页码及可用翻页操作；每项含花束标识、缩略图、名称、单价（元/束）、剩余可预订数量（束）。无匹配也是正常查询结果。 |
| 失败后保证 | 不新增订单，不改变花束、数量或上下架状态；保留已填条件及排序，指出条件错误或读取失败；失败时不把旧结果当作本次成功结果。 |

## 2 输入、输出与检索规则

| 项目 | 约定 |
|---|---|
| 输入 | 名称关键词、花语/适用场景、价格下限/上限、颜色、节日档期、排序方式、页码。未填写的条件不参与限制。 |
| 文本匹配 | 名称去首尾空白后作包含匹配；花语/场景文本同样采用包含匹配。全空白视为空条件。 |
| 组合规则 | 不同字段同时满足；价格包括上下界；颜色与档期按所选值匹配。最低价高于最高价时提示条件错误并保留内容。 |
| 字段来源 | 花名、图片、花语/场景、单价、颜色、档期及状态来自UC-01/UC-07；剩余量还受UC-03/UC-04影响。颜色、档期只使用发布端已有数据及选项，不增设发布必填字段；字段缺失不视作匹配。 |
| 可见范围 | 以本次读取时“已上架且剩余量大于0”为准；下架、售罄记录不进入新的检索结果。空条件也遵循此范围。 |
| 排序 | 默认上新时间倒序，支持价格升序/降序；排序主键相同按花束标识升序，保证静态数据下顺序稳定。 |
| 分页 | 每页10条，显示总数与当前页；翻页保留条件、排序；新查询、切换排序或重置回第一页；重置清空筛选并恢复默认排序。 |
| 输出 | 匹配列表、总数和页码；或无匹配、条件错误、读取失败反馈。结果反映读取时状态，不保证进入详情或提交订单时仍可预订。 |

## 3 正常流程

| 步骤 | 顾客动作 | 系统响应 |
|---|---|---|
| 1 | 进入检索页。 | 以空条件、默认排序读取第一页；后续按第4～6步处理，可展示空列表。 |
| 2 | 填写或修改条件，选择排序，点击查询。 | 保留输入；对新查询将页码设为1。 |
| 3 | — | 规范文本空白并校验价格区间；不合法转A1。 |
| 4 | — | 读取当前可见花束，按条件组合筛选、排序，计算总数并返回指定页；读取失败转A3。 |
| 5 | — | 有匹配时展示缩略图、花名、单价及单位、剩余量、总数与页码；没有匹配转A2。 |
| 6 | 点击下一页或上一页。 | 保留条件、排序，重新读取目标页；无可用下一页时禁用下一页操作；数据变化造成当前页无内容时转A4。 |
| 7 | 选择某一花束。 | 传递花束标识进入[UC-06 查看花束详情](uc-06-view-bouquet.md)，由详情重新读取当前状态。 |

## 4 异常与备选流程

### A1 价格区间错误（分支点：第3步）

- 触发：最低价大于最高价，如100至80元。
- 反馈：指出“最低价不得高于最高价”，保留全部已填内容，允许修改。
- 结果：不作为“无匹配”处理；本次不展示新的查询成功结果，不改库存或订单。

### A2 无匹配或空数据（分支点：第5步）

- 触发：条件合法且读取成功，但匹配数量为0。
- 反馈：显示“暂无匹配花束”，保留条件，提供修改或重置入口。
- 结果：展示总数0，无可翻下一页；不把空结果提示成网络失败。

### A3 读取失败（分支点：第4步及翻页重新读取）

- 触发：请求超时、网络中断或数据读取错误。
- 反馈：显示“查询失败，请重试”，保留本次条件、排序及请求页码。
- 结果：允许按同一条件重试；旧内容如保留须明确其不是本次成功结果；不生成订单、不修改库存。

### A4 翻页期间可见数据减少（分支点：第6步）

- 触发：前一页展示后，花束下架或售罄，目标页已无内容。
- 反馈：提示结果已变化，允许返回上一页或重新查询第一页。
- 结果：仍保留条件与排序；新的每次读取均遵守当前可见范围，不保证多次查询间的数量保持不变。
